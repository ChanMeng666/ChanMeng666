# Rules for the digital twin's voice and knowledge

- `data/voice.yaml` is how the chat on chanmeng.org sounds and what it will not say: persona, manner, avoid, intros, scripted answers, stances, fun facts, deflections, claim guards and example exchanges. It is hand-kept, not a profile shard (`load-profile.mjs` does not read it). Every line is Chan's approved public wording (decided 2026-10-17): change wording only with her.
- The twin Worker in the 2d-portfolio repo (`workers/twin`) reads only `dist/voice.json` and `dist/llms-twin.txt`, from GitHub Pages. Both are generated by `npm run build:twin`; never edit them. A push here changes the twin's knowledge only after the Worker re-fetches.
- Hard limits, in voice.yaml and in every generated line: never Chan's former or Chinese name, even when a source contains it; no prices, rates or hour estimates; nothing about visas, work rights, immigration, notice period or salary; no entry with `show.site` or `show.llms` false (GenLAB, LYZEN, Seismophone, Chromaflow, the `*-mv` projects, the hosted podcasts); no commit counts or solo shares; no money amounts, podcast links (the hosted shows and guest episodes alike) or postal addresses; hello@chanmeng.org is the only address.
- Personal history stops at the decided public tier: maths teacher for about seven years, "rebuild my life somewhere I could breathe freely", New Zealand in 2023 for the Lincoln University master's, minimalism since 2018. Family, relationships, health, money and politics are deflected, never answered.
- Every number or project named in an example must exist in `data/profile/` or `dist/films.json`; every `source` must resolve. `npm run check:twin` fetches the sources; `build:twin` runs offline so the build never depends on a third-party site.
- `scripts/lib/twin-guards.mjs` derives the forbidden names from the data and holds the static patterns and the GAVIGO figure rule; the builder drops the sentence, bullet or row that trips one, and `scripts/check-llms-twin.mjs` fails on any that remains. Fix the source or the rule, never loosen a pattern to pass.
