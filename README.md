## What I build

<sub>What I work on full-time: a language that turns text into floor plans, and the AI design studio built on top of it. Everything else I build is further down.</sub>

### [ArchLang](https://archlang.uk/)

<a href="https://archlang.uk/"><img src="/public/cards/archlang.svg" width="100%" alt="ArchLang: floor plans as code. Text in, a precise architectural drawing out; compiled, linted and measured from one source."></a>


Describe a floor plan in plain text — walls, rooms, doors, windows — and get a precise, dimensioned architectural drawing back. Change one number and exactly one thing moves. It also checks that a plan is actually livable, and powers ArchCanvas, an AI design agent.

<br clear="all">

### [ArchCanvas](https://archcanvas.uk/)

<a href="https://archcanvas.uk/"><img src="/public/cards/archcanvas.svg" width="100%" alt="ArchCanvas, an AI architectural designer: describe your home, get a dimensioned floor plan and a written list of everything it couldn’t get right. The studio drafts in passes, takes an edit in plain words, reviews its own plan, renders it and exports DXF."></a>


An AI design agent for architects and self-builders: describe a building in plain words and it designs a dimensioned floor plan you can actually build from, plus a realistic rendering — then you refine it by talking, on an infinite zoomable canvas.
