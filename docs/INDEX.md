# Knowledge index

The map of this repo: what each source holds and when to read it. Generated by
`scripts/build-kb-index.mjs` from shard headers, doc headings and `package.json`; do not
edit. Rebuild with `npm run build:index`; `npm run check:index` fails when it is stale.
Reading rule: CLAUDE.md, docs/STATE.md and this index are read first (L1); everything
else (L2) is opened on demand, when its "read when" matches the task.
