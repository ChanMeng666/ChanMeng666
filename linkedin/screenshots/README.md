# LinkedIn project screenshots

Screenshots of Chan's live projects for manual upload to the matching LinkedIn → Projects
entries, one folder per project. Captured 2026-06-16 by
`node scripts/capture-linkedin-screenshots.mjs [<slug> …]` (the targets and URLs are in the
script).

- **Public pages only**: no logins, no gated dashboards, so no member or user data appears.
- **The sets are hand-pruned.** Redundant shots were deleted after capture; a re-run brings
  them back.
- For upload prefer the `01`/`02` viewport shots. `99-fullpage.png` is a tall reference, and
  `90-*.png` is a related second site (the She Sharp member-app login).
- **Do not re-run retired sites**: `free-period/` (site retired 2026-10-03) and `pa-tiaki/`
  (deployment taken down 2026-10-07) are kept as archive.
- `sunostats/` is Seismophone (the repo's name).
- FanFic Lab's public story feed is empty, so only the hero and About were worth keeping;
  programming.chanmeng.org's capstone showcase is empty until Demo Day, so the curriculum and
  message board were captured instead.
- No live web page, so no screenshots: echook (CLI), Google News MCP Server (npm package),
  Sanicle.AI / Sanicle.Cloud (domain no longer live), CORDE Mobile (native app).
