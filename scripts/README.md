# scripts/

Generated by `scripts/build-kb-index.mjs` from each script's header comment and
`package.json`; do not edit. Rebuild with `npm run build:index`. A script's own header
comment is its manual: read it before running the script.

Status: **npm** has an npm script; **named in code** appears in another script or a CI
workflow (it may be run or only mentioned there); **run by hand** is named only in docs;
**orphan** is named nowhere in the repo.

## Subdirectories

- `scripts/cards/` (13 modules): One module per README project card, run by `npm run build:cards`
- `scripts/lib/` (14 modules): Shared modules: the profile and brand loaders, copy surfaces, ATS and Typst parsers, triage pages
- `scripts/lib/svg-card/` (4 modules): The animated-card kit: shell, glyph outlining, film frames, layout plan
- `scripts/readme-art/` (5 modules): Banners, pills, the film wall and story art, run by `npm run build:art`
